NEET BEE — Complete Responsive Website
======================================

Responsive multi-page NEET preparation demo built with HTML5, CSS3 and jQuery.

Pages:
- index.html — landing page
- courses.html — Biology, Chemistry and Physics courses
- previous-year-papers.html — sample previous-year practice
- mcq-practice.html — interactive sample MCQ quiz
- audio-learning.html — audio lesson library UI
- mock-tests.html — sample test cards
- pricing.html — plan comparison UI
- about.html — about NEET BEE

Branding: NEET BEE throughout the site.
Mascot: animated bee floating on every page with a gentle buzz/fly animation.
Images: assets/hero-art.jpg and assets/reference-image.jpg use clean, text-free image artwork; promotional text/buttons are HTML overlays, not baked into the image. Both image assets are included locally.

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Internet is required for Google Fonts and jQuery CDN.

Note: login, audio playback, payments and full test bank are demo UI only; backend integrations are not included.
